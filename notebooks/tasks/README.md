# Predictive-maintenance task notebooks

These notebooks contain analysis examples that can apply to more than one
dataset. Task package guides live under
[`pdmdata/tasks/`](../../pdmdata/tasks/README.md).

Available notebooks:

- [Anomaly detection](anomaly-detection.ipynb) with GFD;
- [Fault classification](fault-classification.ipynb) with GFD;
- [Operating-state classification](operating-state-classification.ipynb) with
  OYICD;
- [Condition estimation](condition-estimation.ipynb) with HydSys;
- [Remaining useful life prediction](remaining-useful-life-prediction.ipynb)
  with C-MAPSS;
- [Time-to-event prediction](time-to-event-prediction.ipynb) with C-MAPSS;
- [Survival analysis](survival-analysis.ipynb) with C-MAPSS;
- [Event or sequence forecasting](event-sequence-forecasting.ipynb) with MAPM.

Each notebook downloads a supported dataset, uses Polars for data preparation,
builds a reproducible baseline, and discusses task-specific evaluation and
limitations.

Maintenance-policy evaluation is intentionally omitted. Although MAPM contains
maintenance records, it does not provide the intervention assignment,
counterfactual outcomes, or cost model needed to validate a maintenance policy.

The notebooks are generated by `scripts/generate_task_notebooks.py`. Update
that source and regenerate the notebooks instead of editing generated notebook
JSON directly.

Dataset-specific exploration belongs in `../datasets/`.
