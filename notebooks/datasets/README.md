## Authoring and regeneration guidelines

Keep dataset notebooks focused on:

- loading and validating the source data;
- explaining columns, entities, labels, and time axes;
- visualizing representative samples and class distributions;
- reusing `pdmdata.visualize(...)` or dataset-owned visualization functions
  instead of defining plot logic locally.

Task-level modeling and evaluation examples belong in [`../tasks/`](../tasks/README.md).

To regenerate all script-managed notebooks while preserving saved outputs on
unchanged code cells:

```bash
uv run --locked python scripts/notebooks/generate_all.py
```
