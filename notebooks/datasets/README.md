# Dataset notebooks

These notebooks demonstrate dataset loading, inspection, and interactive
visualization.

- [CWRU bearing recordings](cwru.ipynb): all source collections, normal/fault
  discovery, channel inspection, bounded downloads, waveform/spectrum views,
  and source validation. Generated by `scripts/generate_cwru_notebook.py`.

- [CARE waveforms](care.ipynb) loads a selected farm/event and shows full-period
  and prediction-detail Matplotlib waveforms, with saved static outputs for GitHub.
- [Interactive visualization showcase](visualization-showcase.ipynb) uses
  C-MAPSS, GFD, and MAPM to demonstrate the reusable Plotly API.

- [ALPI alarm events](alpi.ipynb): source-faithful event loading, per-machine
  inventory, and duplicate/timestamp diagnostics. Generated by
  `scripts/generate_alpi_notebook.py`.

Keep these notebooks focused on:

- loading and validating the source data;
- explaining columns, entities, labels, and time axes;
- visualizing representative samples and class distributions;
- reusing `pdmdata.visualize(...)` or dataset-owned visualization functions
  instead of defining plot logic locally.

Task-level modeling and evaluation examples belong in `../tasks/`.

The showcase is generated by `scripts/generate_visualization_showcase.py`.

- [Backblaze drive histories](backblaze.ipynb): local inventory, drive selection, and SMART waveforms.

- [GDD machine states](gdd.ipynb): state IDs, durations, transitions, and motor waveforms.

- [MetroPT2 operating cycles](metropt2.ipynb): compressor waveforms, control switching, and a short zoom.

- [GFD vibration recordings](gfd.ipynb): healthy/broken comparisons, load profiles, and sensor correlations.

- [OYICD process cycles](oyicd.ipynb): unique recording inventory, month/mode coverage, and eight-signal waveforms.

- [PPD process recordings](ppd.ipynb): eight-sequence loading, Leave-One-Out splits, missing values, and waveform comparisons.

- [HYDSYS hydraulic cycles](hydsys.ipynb): native sampling rates, cycle-level condition labels, and valve comparisons.

- [IMS bearing experiments](ims.ipynb): 20 kHz vibration snapshots, bearing assignments, early/late comparisons, and RMS degradation histories.

- [C-MAPSS engine trajectories](cmapss.ipynb): subset inventories, engine selection, operating-condition changes, and explicit RUL targets.

- [MAPM Azure sample tables](mapm.ipynb): multi-table load and Plotly telemetry/error views. Generated by `scripts/generate_mapm_notebook.py`.

- [N-CMAPSS trajectories](ncmapss.ipynb): variant inventory, unit RUL, and sensor plots. Generated by `scripts/generate_ncmapss_notebook.py`.

- [SCANIA Component X](scania_x.ipynb): train inventory, TTE labels, and counter trajectories. Generated by `scripts/generate_scania_x_notebook.py`.

- [XJTU-SY bearings](xjtu_sy.ipynb): bearing inventory, RMS features, and RUL plots. Generated by `scripts/generate_xjtu_sy_notebook.py`.
